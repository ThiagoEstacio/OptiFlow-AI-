📝 Comandos de Exemplo

Você também pode criar widgets individualmente no Dashboard Builder usando estes comandos:

  1. 💨 "Crie um gauge de temperatura com range de 0 a 100 graus"
  2. 📈 "Adicione um gráfico mostrando pressão das últimas 24 horas"
  3. 🎯 "Mostre um KPI de eficiência com meta de 85%"
  4. 📊 "Crie um gráfico de vibração das últimas 2 horas"
  5. 🔴 "Adicione um indicador de status da máquina"
💡 Como usar:
1. Acesse Dashboard Builder
2. Clique no botão "AI Assistant" (gradiente azul/roxo com ícone ✨)
3. Digite qualquer um dos comandos acima
4. O widget será criado e posicionado automaticamente!
